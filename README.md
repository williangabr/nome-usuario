# 👋 Qual é o seu nome?

Um projeto simples desenvolvido para praticar **HTML, CSS e JavaScript**, utilizando manipulação do DOM e eventos.

## 💻 Sobre o projeto

O usuário digita seu nome e clica no botão **Confirmar**. O JavaScript captura o valor digitado, formata o nome e exibe uma mensagem de boas-vindas.

### Funcionalidades

* Campo para digitar o nome
* Botão de confirmação
* Formatação do primeiro nome
* Mensagem personalizada
* Manipulação do DOM com JavaScript
* Evento de clique

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript

## 📚 O que pratiquei

* `document.getElementById()`
* `addEventListener()`
* `.value`
* `.textContent`
* `.charAt()`
* `.slice()`
* `toUpperCase()`
* `toLowerCase()`
* Template literals

## 🚀 Como executar

Baixe ou clone o projeto e abra o arquivo `index.html` no navegador.
